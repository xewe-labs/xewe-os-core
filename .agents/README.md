# .agents — xewe agentic workspace

xewe_agents_version=2.3.0

This folder holds what coding agents need in this project. Agents start at `AGENTS.md`.

| File | Owner |
|---|---|
| `README.md`, `AGENTS.md`, `RULES.md` | global: copied from https://github.com/maxdokukin/dot_agents at every session start; edit them there, not here |
| `PREFERENCES.md`, `skills/`, `users/<login>/handoffs/` | this project; committed |

Global skills and personal preferences are not in this folder; they live in `~/.agents` on
each machine that ran dot_agents' `setup.sh`.
