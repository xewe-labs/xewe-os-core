# Decisions

Each line records one decision that a later change could undo by accident. Write it as a date,
the decision, and the reason, with the newest line last.

The dates are the commits that first recorded each decision (git log -S), so the decision itself
may be older.

2026-10-09 New code stays on C++17 and uses `xewe::span`, because the host tests also build at `-std=c++17`. `Nvs::write_blob` is the one exception and keeps its `std::span` signature.
2026-10-09 Feature modules such as Wi-Fi, buttons and the web interface live in xewe-os-modules, so the core knows no module except `System`.
2026-10-09 `str::lower` and `str::to_lower` both stay public, because both have callers.
2026-10-09 A struct is versioned with its own `schema` field, because `kBlobVersion` is one constant for the whole library's wire format.
2026-10-11 The release card is generated by `scripts/release.sh --prepare` and never written by hand, because it records what ran on which tree. A `releases/<version>/testcard.md` makes the script refuse.
